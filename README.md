# LOOI Game - 模拟经营游戏

一个基于 Godot 4 开发的 LOOI 模拟经营游戏，包含经济系统、打工系统和与用户的关系系统。

## 功能特点

- 💰 **经济系统**: LOOI 拥有自己的金币，可以进行消费和积累
- ⚡ **打工系统**: LOOI 可以通过挖矿、交易、任务等方式赚取金币
- 📈 **升级系统**: 通过学习和完成任务获得经验值升级
- ❤️ **好感度系统**: 与用户关系绑定的经济行为
- 🛒 **商店系统**: 购买道具增强 LOOI 能力

## 打工类型

| 类型 | 耗时 | 说明 |
|------|------|------|
| ⛏️ 挖矿 | 5秒 | 基础赚金币方式 |
| 💰 交易 | 8秒 | 中等收益 |
| 📜 任务 | 12秒 | 高收益任务 |
| 📚 学习 | 6秒 | 获得经验值 |

## 运行要求

- Godot Engine 4.2+
- 支持 GL Compatibility 渲染模式

## 运行方式

1. 克隆仓库
2. 使用 Godot Engine 4.2+ 打开项目
3. 点击运行按钮或按 F5

## 项目结构

```
looi-godotgame/
├── scenes/           # 游戏场景
├── scripts/          # GDScript 脚本
│   ├── looi.gd       # LOOI 核心类

│   └── main_ui.gd    # UI 控制器
├── resources/        # 游戏资源
├── project.godot     # 项目配置
└── README.md         # 说明文档
```
