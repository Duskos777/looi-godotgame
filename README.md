# LOOI Game - 模拟经营游戏

一个基于 Godot 4 开发的 LOOI 机器人模拟经营游戏，包含丰富的经济系统和互动玩法。

## 功能特点

- 💰 **经济系统**: LOOI 拥有金币系统，可以消费和积累
- ⚡ **打工系统**: 挖矿、交易、任务、学习赚取金币和经验
- 📈 **升级系统**: 获得经验值升级，提升能力
- ❤️ **好感度系统**: 与用户关系绑定的互动系统
- 🛒 **商店系统**: 购买道具、种子、宠物
- 🎒 **背包系统**: 存放和管理道具
- 🌾 **农场系统**: 种植作物，收获出售赚钱
- 🐕 **宠物系统**: 领养宠物，获得金币加成
- 🎮 **小游戏**: 点击得分小游戏
- 🍔 **快餐店**: 模拟经营快餐店

## 运行要求

- Godot Engine 4.2+
- 支持 GL Compatibility 渲染模式

## 运行方式

1. 克隆仓库
2. 使用 Godot Engine 4.2+ 打开项目
3. 点击运行按钮或按 F5

## 项目结构

```
looi-godotgame/
├── scenes/           # 游戏场景
├── scripts/          # GDScript 脚本
│   ├── looi.gd       # LOOI 核心类
│   ├── game_manager.gd  # 游戏管理器

├── resources/        # 游戏资源

```
